About Me

Page | 03

I’m a software engineer driven by curiosity, continuous learning, and the desire to build things that matter.

My journey in technology has been shaped by a simple idea:

The best way to understand technology is to build with it.

I have explored different areas of computing, including software development, networking, cryptography, artificial intelligence, machine learning, data analysis, and computer vision.

Rather than limiting myself to one area, I enjoy understanding how different technologies connect and using them together to solve problems.

I’ve built and experimented with projects ranging from web-based management systems and communication platforms to security-focused systems and digital products. Each project has been an opportunity to learn something new, solve a real problem, and improve how I approach software development.

I’m particularly interested in the future of technology in Africa, and how software and emerging technologies can be used to create opportunities, improve businesses, and solve problems that affect everyday people.

ChatApp

02 Currently in Development

Attachify

A platform to help students discover attachment and internship opportunities across Kenya. It is intended to aggregate current opportunities from company websites using a Python web scraper and update them automatically, and to integrate M-Pesa for payments.

Python, Web Scraping, Automation, Data Processing, M-Pesa, Web Development

03 Currently in Development

Algorithmic Mind

A web-based technology editorial and news platform covering software, artificial intelligence, emerging technologies, startups, events, products and industry developments. A Python web scraper is intended to collect current technology news from local and global sources and store it in a database for review. The final workflow includes review and publishing by an editor.

Python, Web Scraping, Automation, Databases, Editorial Systems, Software, Artificial Intelligence

05 Live

Salon Management System

A web-based salon management system built as a school project. It implements role-based access control for Customer, Staff and Administrator, and M-Pesa STK Push using the sandbox environment. Role-Based Access Control, M-Pesa STK Push, Authentication, Authorization, Database Design
